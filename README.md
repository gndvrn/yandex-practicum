# Портфолио Специалиста по Data Science

Этот репозиторий содержит проекты, выполненные в рамках программы **Специалист по Data Science** в Яндекс Практикуме (2023). Каждый проект демонстрирует практическое применение машинного обучения, статистического анализа и техник предобработки данных в различных бизнес-областях.

## Ключевые навыки и технологии

**Машинное обучение:** Классификация, Регрессия, Прогнозирование временных рядов, NLP, Компьютерное зрение  
**Библиотеки:** Pandas, NumPy, Scikit-learn, CatBoost, LightGBM, XGBoost, TensorFlow/Keras, NLTK, Plotly  
**Техники:** Feature Engineering, Подбор гиперпараметров, Кросс-валидация, Bootstrap, Балансировка классов  

---

## Обзор проектов

### 02 | Анализ кредитоспособности заемщиков банка 💳
**Область:** Финансы  
**Задачи:** Предобработка данных, проверка гипотез, статистический анализ  
**Результат:** Выявлены закономерности в поведении заемщиков на основе семейного статуса, дохода и цели кредита

### 03 | Анализ данных о продажах недвижимости 🏡
**Область:** Недвижимость  
**Задачи:** Исследовательский анализ данных, feature engineering, анализ факторов цены  
**Результат:** Создана основа для модели предсказания цен; определены ключевые драйверы цены (локация, площадь, комнаты)

### 05 | Анализ продаж компьютерных игр 🎮
**Область:** Ритейл  
**Задачи:** Статистический анализ, проверка гипотез, региональное профилирование пользователей  
**Результат:** Стратегия прогнозирования продаж на 2017 год; региональные инсайты; анализ жизненного цикла платформ

### 07 | Система рекомендаций мобильных тарифов 🤳🏼
**Область:** Телеком  
**Задачи:** Бинарная классификация, сравнение моделей (LogisticRegression, RandomForest)  
**Результат:** Точность 80%+ в рекомендациях тарифов на основе поведения клиентов

### 08 | Прогнозирование оттока клиентов банка 🏦
**Область:** Финансы  
**Задачи:** Классификация, работа с дисбалансом классов (upsampling/downsampling)  
**Результат:** F1-score 0.619, ROC AUC 0.86 с использованием RandomForestClassifier

### 09 | Выбор локации для нефтяной скважины 🛢
**Область:** Энергетика  
**Задачи:** Линейная регрессия, метод Bootstrap, анализ прибыли и рисков  
**Результат:** Определен наиболее прибыльный регион с риском убытков <2.5%

### 10 | Прогнозирование эффективности восстановления золота ⚜️
**Область:** Добыча/Производство  
**Задачи:** Регрессия с кастомной метрикой sMAPE, оптимизация процесса  
**Результат:** Финальный sMAPE 5.66 с использованием RandomForestRegressor

### 11 | Шифрование данных страховой компании 🔐
**Область:** Страхование/Безопасность данных  
**Задачи:** Разработка алгоритма матричного шифрования, обфускация данных  
**Результат:** Алгоритм защиты данных с сохранением точности модели (R² не изменён)

### 12 | Прогнозирование цены автомобиля 🚗
**Область:** Автомобильная индустрия  
**Задачи:** Градиентный бустинг, кодирование признаков, обработка выбросов  
**Результат:** RMSE 1524 с использованием CatBoostRegressor; баланс скорости и точности

### 13 | Прогнозирование заказов такси 🚕
**Область:** Транспорт  
**Задачи:** Анализ временных рядов, декомпозиция тренда и сезонности  
**Результат:** RMSE 46.81 для прогноза заказов на час вперед с использованием LinearRegression

### 14 | Определение токсичных комментариев 🤬
**Область:** NLP/Модерация контента  
**Задачи:** Предобработка текста (токенизация, лемматизация), TF-IDF, классификация  
**Результат:** F1-score 0.754 с использованием LogisticRegression с авто-балансировкой

### 16 | Определение возраста по фотографии 👨🏼‍🎤
**Область:** Компьютерное зрение  
**Задачи:** Transfer learning с ResNet50, аугментация изображений  
**Результат:** MAE 6.05 для предсказания возраста клиентов по фото

### 17 | Прогнозирование температуры стали 🌡
**Область:** Металлургия/Промышленность  
**Задачи:** Многомерная регрессия, анализ корреляций признаков, оптимизация энергопотребления  
**Результат:** MAE 6.43 с использованием CatBoostRegressor для снижения расхода электроэнергии
